# Task List & Monthly Calendar

A simple and intuitive frontend application designed to help users organize their daily tasks, manage their schedules, and keep track of their monthly activities.

## Features

### Task List

- Create new tasks.
- View all tasks in a list.
- Mark tasks as completed or pending.
- Edit existing tasks.
- Delete tasks.
- Organize tasks by priority or status.

### Monthly Calendar

- View a complete month in a calendar layout.
- Navigate between months.
- Select a specific day to view its tasks.
- Display scheduled tasks on their corresponding dates.
- Easily identify days with pending or completed tasks.

### User Interface

- Clean and intuitive design.
- Responsive layout for desktop, tablet, and mobile devices.
- Easy navigation between the task list and calendar.
- Visual indicators for task status and priority.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to access the application.
